# 用户使用说明

「地铁可达圈」帮助你回答一个问题：**在给定的出行时间内，从某个地点出发，依靠地铁（可含公交）能到达多大的区域？**

## 一、界面速览

- **顶部**：Logo、城市切换、帮助按钮。
- **左侧面板**：起点搜索、出行方式、出行时间、查询按钮、已选起点列表。
- **右侧地图**：展示起点与可达圈多边形；底部是图例。
- **底部状态栏**：显示当前操作提示 / 状态。

## 二、选择起点（2 种方式）

1. **直接点击地图**：在地图上随意点击一个位置，系统会自动逆地理编码为地址并加入起点列表。
2. **搜索**：在左侧“起点”输入框输入地址、地铁站名或 POI 关键词，会弹出联想结果：
   - 选中后即可加入起点（地铁站会带“地铁站”标记）。

> 最多同时添加 **3 个起点**。超过会提示且无法继续添加。

## 三、设置出行条件

- **出行方式**：地铁 / 公交 / 地铁+公交（默认）。
- **出行时间**：拖动滑块调节，范围 **1–60** 分钟（默认 30）。

> 可达圈接口最多支持 60 分钟，超过会报错。

## 四、查询可达圈

点击 **“查询可达圈”** 按钮，系统将为当前所有起点分别计算等时圈，并以不同颜色绘制在地图上，同时自动调整视野以完整显示：

- 地铁仅：`SUBWAY`
- 公交仅：`BUS`
- 地铁 + 公交：`SUBWAY,BUS`（默认）

每个起点对应一种颜色（见底部图例）。

## 五、多起点对比与交集

1. 添加 2–3 个起点并查询，地图上会叠加显示多个颜色的可达圈。
2. 勾选 **“显示多起点可达圈交集”**，系统会用 **黄色** 高亮所有可达圈的重叠区域（需已查询出有效结果）。

## 六、管理起点

- 点击起点列表中的某一项：高亮该起点并让视野定位到它。
- 点击列表项右侧的 **✕**：删除该起点及其可达圈。
- **清空** 按钮：清除所有起点与图层。

## 七、城市切换

顶部可切换城市（杭州 / 北京 / 上海 / 广州 / 深圳）。切换会清空当前起点与图层，并重新加载该城市的地铁站点数据。

## 八、关于“演示模式”

若未在 `.env` 中配置高德 Key，应用会进入 **演示模式**：地图区域显示一个示意画布，用模拟的等时圈多边形展示全部交互逻辑（点击拾取、多起点、交集、时间/方式联动）。填入真实 Key 后自动切换为高德实时地图。

## 九、常见问题

| 现象 | 处理 |
|------|------|
| 地图不显示 / 显示“演示模式” | 检查 `.env` 是否已填真实 Key（Web端(JS API) 类型）。 |
| 可达圈为空 | 检查起点是否在地铁/公交覆盖范围内，时间是否在 1–60 分钟内。 |
| 地铁站点搜索不到 | 地铁图 API 为 Beta，数据结构可能变化；可改用地址/POI 搜索或点击地图。 |
| 接口报错/超时 | 可达圈接口有 QPS 限制，程序已顺序调用；稍后重试。 |
